# Модуль 2 — практические задания 1–10

Проект для Android Studio, Kotlin и Jetpack Compose. Откройте папку проекта через File → Open, дождитесь синхронизации Gradle и нажмите Run. Выбор задания расположен в горизонтально прокручиваемой полосе сверху.

## Задания

1. Hello(name: String?) выводит приветствие или «Имя не задано». Параметр greetingName в MainActivity.kt определяет значение при запуске. Отдельные APK с именем и с null сохранены отдельно для демонстрации двух сборок.
2. HelloPreview содержит три @Preview: portrait, landscape, round. Включён системный UI. Круглый дисплей — 200 × 200 dp, фон жёлтый. Для просмотра откройте MainActivity.kt → Split или Design → Build & Refresh.
3. Строка compose_description находится в strings.xml. Реализованы зелёный курсив 16 sp по центру, одна строка с многоточием и подчёркнутый чёрный текст 24 sp на зелёном фоне с отступом первой строки 48 sp.
4. Кнопка занимает всю ширину, имеет скругление 16 dp, серую границу 2 dp, тень 4 dp, светло-серый фон и чёрную надпись.
5. Серый контейнер высотой 100 dp. Оранжевый круг с инициалами расположен по центру, вертикальные отступы 16 dp. Диаметр круга — 68 dp.
6. circle.xml содержит вектор из условия. OriginalCircle размещает изображение 48 × 48 dp справа вверху чёрного контейнера 240 × 120 dp. StretchedCircle растягивает изображение в синем контейнере через ContentScale.FillBounds и окрашивает его ColorFilter.tint в фиолетовый.
7. ContactColumn, ContactList и ContactRow воспроизводят три образца из задания. Для списка используется Column, для строки с картинкой справа — Row. Звезда — локальный векторный ресурс contact_star.xml.
8. WaterTracker увеличивает воду на 250 мл. Начальное значение 100 мл сохранено из исходного кода условия. «Завершить день» обнуляет воду; при 1500 мл и больше увеличивает серию дней, иначе обнуляет её. Состояние сохраняется при пересоздании и переключении заданий.
9. WaterTrackerTest.kt содержит инструментальные UI-тесты кнопок, порога 1500 мл, последовательных успешных дней, сброса серии и восстановления состояния.
10. ShoppingCartScreen вычисляет сумму из текущего списка. Товары добавляются и удаляются с конца; пустая корзина скрывает кнопку удаления. Toast «Доставка бесплатная!» вызывается обработчиком добавления при новой сумме больше 500. Побочных накоплений суммы во время рекомпозиции нет. Корзина сохраняется при пересоздании экрана.

Основной код заданий 1–5 находится в MainActivity.kt; заданий 6–10 — в Tasks6To10.kt. Имя «Амир» и инициалы «А» меняются в MainActivity.kt.

## Запуск тестов

В Android Studio откройте WaterTrackerTest.kt из app/src/androidTest/java/com/example/myapplication и запустите класс. PracticeReviewTest.kt проверяет остальные экраны, корзину и переключение заданий. Нужен запущенный эмулятор или подключённое устройство.

Из терминала в папке проекта:

    .\gradlew.bat :app:assembleDebug :app:connectedDebugAndroidTest

Архив исходников не содержит кэши, ключи, файлы SDK и local.properties. При открытии Android Studio использует установленный на компьютере SDK.
